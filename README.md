# StudioLens — Preview Site

This is a lightweight preview for a photography & videography studio website.

## Highlights
- Responsive layout (pure HTML/CSS/JS)
- Portfolio with category filters
- Accessible forms & lazy-loaded images
- SEO: meta tags, OpenGraph, JSON-LD schema

## Run locally
```bash
# unzip then
cd studio-website-preview
python3 -m http.server 5500
# open http://localhost:5500
```
